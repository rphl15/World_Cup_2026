# 🏆 World_Cup_2026: Análise Estatística e Preditiva

Este projeto tem como objetivo centralizar dados, estatísticas e análises profundas sobre a Copa do Mundo de 2026. Utilizamos uma abordagem multidisciplinar combinando o poder de processamento do **Python**, a estruturação de dados em **SQL** e a análise estatística rigorosa em **R**.

## 🛠️ Tecnologias e Ferramentas
* **Python:** Extração de dados (Web Scraping/APIs) e pré-processamento.
* **SQL:** Armazenamento e consultas estruturadas para métricas de performance.
* **R:** Modelagem estatística, testes de hipóteses e visualizações avançadas.

## 📊 Fluxo de Dados
1.  **Coleta:** Scraping de fontes como SofaScore/FBRef (Python).
2.  **Limpeza:** Tratamento de valores nulos e normalização (Pandas).
3.  **Armazenamento:** Criação de um banco de dados relacional para histórico de partidas (SQL).
4.  **Análise:** Aplicação de modelos lineares ou simulações de Monte Carlo (R).

## 🚀 Como Executar o Projeto
1. Clone o repositório: `git clone https://github.com/seu-usuario/World_Cup_2026.git`
2. Instale as dependências: `pip install -r requirements.txt`
3. Acesse a pasta `/scripts` para ver os códigos de coleta.
